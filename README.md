# Plannit Studio API

Datos de prueba para la app móvil Plannit Studio (marketplace de decoración de eventos, San Salvador).
Servidos como API REST mediante my-json-server:

- `GET  https://my-json-server.typicode.com/Francisco10-24/plannit-studio-api/paquetes`
- `GET  https://my-json-server.typicode.com/Francisco10-24/plannit-studio-api/extras`
- `GET  https://my-json-server.typicode.com/Francisco10-24/plannit-studio-api/decoradores`
- `POST https://my-json-server.typicode.com/Francisco10-24/plannit-studio-api/solicitudes` (responde 201, no persiste)
